SIC Code Guide

What is a SIC code?

SIC stands for Standard Industrial Classification. It is a system used to organize businesses by their primary economic activity. Many legacy records, business directories, insurers, and private-sector systems still use SIC codes alongside or instead of NAICS codes.

What is the difference between SIC and NAICS?

SIC and NAICS are separate industry classification systems. NAICS is newer and uses a different code structure. Check the exact classification requested before submitting a code.

How do I choose a SIC code?

Search for the activity that best describes your primary business activity, then compare the detailed four-digit descriptions before selecting a code.

How many digits are in a SIC code?

This finder includes the supplied two-digit major groups and four-digit industry codes.

Can I search SIC codes by keyword?

Yes. Search by an industry phrase, business activity, full code, or code prefix to rank the closest matching entries.
