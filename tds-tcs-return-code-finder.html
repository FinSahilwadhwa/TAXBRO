FAQs

Common questions about the TDS and TCS Return Code Finder.

This page is designed for practical lookup during return preparation and section-mapping review.

Is this different from the HSN and SAC finder?

Yes. HSN and SAC are GST classification codes. This page is for return codes used in TDS/TCS return work and for mapping old sections to Income-tax Act 2025 references.

Can I search by old section instead of return code?

Yes. Search terms like 194C, 194J, 194A, or 194R work directly against the indexed rows.

Why does the page have a TCS filter if the source PDF has no TCS rows?

The UI is ready for future source data. The current supplied PDF extracted into this page contains TDS rows only, so the TCS count currently shows zero.

Can I copy a result?

Yes. Each result has a copy button that includes the return code, category, old section, new section, payment nature, rate, and threshold.
